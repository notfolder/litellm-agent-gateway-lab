## 決定事項

- 文脈独立審査は文脈あり審査と並列、Jev は使わない、Claude Code にも掛ける（外せる）。審査官は ChatGPT。Claude Max のトークンは規約上使わず、Anthropic の API キーも使わない
- 審査の記録は main の監査ログに乗せる（審査ごとに 1 件、`review_kind`）。書けなくても止めない。保持は `audit-raw` の 90 日。引数は冒頭 200 文字だけ（全文は要求の本文）
- 審査の利用料は審査官ごとに分ける。既存環境の請求の単位への追加は管理用の API で行う（`./lab` は管理者の設定を書き換えない）
- 監査ログの記録の確認は `./lab test-audit`。検索アプリの単体テストはイメージのビルドの中で流す
- **docs/spec.md と docs/design.md は、実装と試験が終わってから更新する。更新するときは継ぎ足しではなく、単独で読める文書にする**（ユーザー指示 2026-10-12）
- **仕様と設計に、ヒアリング外のことを勝手に決めて書かない。未決は選択肢・おすすめ・根拠を付けて確認する**（ユーザー指示）
