# 送信するファイルの中身を機密データチェックに渡す仕組みを実装した

更新: 2026-10-16 00:28 JST
セッション: 4063215a-abab-4967-9a18-32e030db1165
ログ: ./session.md

## 概要
名前から機密か分からないファイルを外へ送る操作について、ゲートウェイが読み取りを差し込んで中身を審査官に渡す仕組みを、ブランチ `feature/isolated-content-read` に実装・試験・コミットした（未 push、Claude Code の 2 件が未決）。

## やったこと

- **`LAB_NOREVIEW_KEYS=true ./lab up` が効かない件**: `./lab` は `.env` だけを読む。シェルの値が `.env` と違えば警告を出すようにした（`labtool/core.py`）。
- **`docs/manual-check.md` 2.3**: 試験用リポジトリを作るコマンドに、シナリオの材料（誤字のある README、顧客一覧.csv、作業メモ.txt、data/customers.csv の変更、deploy.sh）を足した。
- **審査ありの Codex が審査なしのキーで送っていた件**: 同じ `CODEX_HOME` の Codex の常駐プロセス（app-server）が起動時のキーを持ち続けていた。審査なしの `CODEX_HOME` を `.codex-lab-noreview` に分けた。
- **手順書（manual-check）の人による確認は、ユーザーの指示でいったん中止。**
- **送信するファイルの中身の審査（本題）**: 仕様と設計は `.history/2026-10-13-送信するファイルの中身の審査/` の変更仕様書・変更設計書（14 章に経緯と試験結果）。
  - 審査官が `allow` / `block` / `need_content`（＋ファイル）を返す。`need_content` なら、ゲートウェイが送信のツールコールを「説明の文＋読み取りのツールコール」に差し替える。読み取りのコマンドはゲートウェイが一字一句決める。
  - シェルのツールは、ツールの一覧から決まった規則で選ぶ（Codex の `exec`、または `command` の文字列だけを取る関数がちょうど 1 つ）。無ければ拒否の文で読み取りを示す。
  - 送信の直前のツールコールが指定どおりの読み取りなら、その出力だけを審査官に渡す。上限（24KB・3 ファイル、設定可）超過、読めない（画像・圧縮・暗号）、再要求、引数に無いファイル、作業フォルダの移動と相対パスの組み合わせは止める。
  - Codex がツールの一覧を `input` の中の `additional_tools` で送っていることを突き止めて読めるようにした（審査官にツールの定義が「定義なし」で渡っていた問題も直った）。
  - 最初の「拒否の文で読ませる」方式は本物の試験で失敗した（拒否の文はモデル自身の発言扱いになり手番が終わる、Codex は読み取りを断る）。そのためツールコールへの差し替えに変えた。
- **試験**: 単体（構築ツール 38・ガードレール 72）全通過、疎通 45 件全通過、事例試験（本物の審査官、各 3 回）60 件全期待どおり。本物の Codex は差し替えた読み取りを実行した（そのあとモデル自身が個人情報に気づき送信を中止）。本物の Claude Code は無害なファイルで最後まで通った。個人情報のファイルでは、下の未決 2 件のため中身による判定まで届かなかった（どちらも止まる側）。
- **コミット**: `2081bb7`（変更仕様書・変更設計書）、`67d37f3`（前半の 3 つの修正）、`bcc8c62`（中身の審査の実装）。push はしていない。

## 決定事項

- 中身はゲートウェイ指定のコマンドで読ませ、指定どおりの読み取りの出力だけを機密データチェックに渡す（会話の他部分は渡さない）。審査官に中身が渡るのは認める。
- シェルのツールは決まった規則で選び、LLM には選ばせない。読み取り専用のツールは使わない（ユーザー回答「A」）。
- 相対パスと作業フォルダの移動の組み合わせは、決まった規則でも止める（13-1 B）。
- 前半の 3 つの修正と今回の実装は、このブランチで別々のコミットにした（確認事項 3 の回答が無いまま、おすすめの A で実施）。

## 次にやること

1. 未決 2 件をユーザーに確認する（前回の報告の確認事項 1・2）。

   - Claude Code が `cd <絶対パス> && curl …` で送ると、中身を読まずに止まる。おすすめ: 今のまま止める。
