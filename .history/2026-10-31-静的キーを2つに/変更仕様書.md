# 変更仕様書: バケットの静的キー（IAM ユーザー）を 5 つから 2 つに

作成: 2026-10-31
状態: 実装済み・GCP で配備と試験済み（2026-10-31。結果は変更設計書 4 章）。docs/spec.md 12.2 に反映済み
この文書の役割: **何を満たすか（要件）と、何を決めたか（決定）**。どう作るかは `変更設計書.md`

## 0. 背景と決定事項

### 0.1 背景

VM 3 台構成（`LAB_TARGET=aws-ec2` / `gcp-vm`）のバケットは役割ごとに 5 つの静的キー（IAM ユーザー／サービスアカウント）で使っていた。
本番ではクラウドの資源を別部署に依頼して作ってもらうため、「IAM ユーザー 5 本は複雑すぎる」（2026-10-31）。

### 0.2 決定事項（2026-10-31、ユーザーの回答）

| # | 問い | 決定 |
|---|---|---|
| 1 | 鍵の数と分け方 | **2 つ**。「原本を書く」（LiteLLM）と「監査アプリ・運用」（整形の定期処理、検索アプリ、DB のバックアップ、イメージ置き場、k3s の設定、構築ツールの操作者）。「監査アプリと運用は一つで良い」 |
| 2 | バケットの数 | **1 つのまま**（A）。ディレクトリで分ける |
| 3 | 進め方 | 実装と単体テストのあと GCP で配備・試験・片付けまで確かめて push（A） |
| 4 | 閲覧と管理操作の記録の保持 | **90 日**（原本と同じ。2026-10-11 の 13 か月は「答えた覚えが無い」） |
| 5 | 日次の集計と月次の精算の保持 | **13 か月のまま**（鍵の数とは別の、ライフサイクルの日数） |

受け入れる点: バックアップやイメージ置き場の処理が乗っ取られた場合に原本を読める（消すことはできない）。

## 1. 要件

- R1. VM の環境の静的キーは 2 つ。`litellm-writer`（原本を書く）と `lab-app`（それ以外）。Mac の RustFS（4 利用者）は変えない。
- R2. `litellm-writer` の権限は今のまま（`audit-raw/raw/` に置く ＋ 保持を付ける。読めない・消せない）。
- R3. `lab-app` の権限は、今の audit-compactor・audit-viewer・pg-backup・registry・操作者の権限の合併: バケットの一覧、`audit-raw/` `audit-access/` `audit-derived/` を読む、`audit-access/`（保持付き）と `audit-derived/` に置く、`audit-derived/` を消す（片付け）、`pg-backup/` `images/` `cluster/` の全操作、バケットの設定の読み取り。
- R4. どちらの鍵も、`audit-raw/` と `audit-access/` の版の削除・保持の回避・リーガルホールド、バケットの設定の変更は明示的に拒否する。
- R5. `.env` の項目は `LAB_VM_S3_LITELLM_WRITER_KEY/_SECRET`、`LAB_VM_S3_LAB_APP_KEY/_SECRET`（GCP は加えて `LAB_VM_GCS_REGISTRY_KEY_JSON`: `lab-app` のサービスアカウントの JSON キー）。
- R6. managed の provision は 2 つを作り、前の版が作った 6 つ（5 役割 ＋ 操作者）が残っていれば `./lab down` で消す。provided は 2 つを用意する側から受け取る。
- R7. 構築ツールの操作者はバケットに `lab-app` の鍵で入る（GCP は必須、AWS は無ければ自分の資格情報）。
- R8. 監査の試験（`test-audit`）の「原本は書き込み用・検索アプリの資格情報では消せない」はそのまま通る。

## 2. 検証項目

| 項目 | 合格 |
|---|---|
| `./lab up`（managed、GCP） | 全段階が通る。サービスアカウントは `litellm-writer` と `lab-app` の 2 つだけ |
| 自己確認（objectstore の段階） | 書き込み用は原本を読めない・消せない、`lab-app` は原本に書けない・消せない、保持を外せない |
| `test-smoke` / `test-audit` | 前回と同じ結果 |
| provided の前提の検査 | `.env` に 2 組（GCP は JSON キーも）あれば通る |
| `./lab down` | サービスアカウント 2 つと旧 6 つが消える |
